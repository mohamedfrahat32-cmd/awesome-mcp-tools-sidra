# Contributing to Awesome MCP Tools

Thank you for your interest in contributing! This list aims to be a high-quality, curated resource for the MCP ecosystem.

## Guidelines

### What belongs here

- MCP servers that are actively maintained and have working documentation
- SDKs, frameworks, and tools that meaningfully support the MCP ecosystem
- Learning resources that are accurate and up to date

### What does not belong here

- Abandoned or archived projects (no commits in 6+ months with open issues)
- Forks with no meaningful changes from the upstream project
- Projects that only mention MCP in passing but do not implement the protocol
- Self-promotional entries without demonstrated community value

### How to add an entry

1. Fork this repository
2. Add your entry to the appropriate category in `README.md`
3. Use the following format:

```markdown
- [Project Name](https://github.com/owner/repo) - A concise description of what it does and why it is useful. ![GitHub Repo stars](https://img.shields.io/github/stars/owner/repo?style=flat)
```

4. Keep descriptions concise (one sentence, under 150 characters)
5. Do not use superlatives like "best" or "ultimate" in descriptions
6. Place your entry alphabetically within its category
7. Submit a pull request with a clear title

### How to suggest a new category

If your entry does not fit any existing category, open an issue first to discuss whether a new category is warranted. Categories should have at least 3 entries to justify their existence.

### Quality standards

Before submitting, verify that:

- [ ] The project has a README with setup instructions
- [ ] The project installs and runs without errors
- [ ] The project implements MCP (not just mentions it)
- [ ] The link points to the correct repository
- [ ] The description accurately reflects what the project does

### Reporting broken links or outdated entries

Open an issue with the title "Broken: [Project Name]" or "Outdated: [Project Name]" and include details about what is wrong.

## Code of Conduct

Be respectful and constructive. We are all here to build a useful resource for the MCP community.
